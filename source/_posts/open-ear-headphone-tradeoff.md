不入耳的形态一旦确定，声学上的账就定了：耳道不密封，低频声压建立不起来；而漏音不是另一件事，是同一件没密封的事从另一侧看过去的结果。所以讨论开放式耳机，把"低音怎么补回来"和"声音怎么别漏出去"当成两个独立课题来处理，一定会得出互相矛盾的结论——任何一条把低频做厚的路，都在加剧另一侧；任何一条把漏音压下去的路，都在牺牲已经很少的低频能量。

这篇只讲这些取舍发生在哪一层、代价是什么、怎么验证。不谈具体产品，也不给结论性推荐。

## 一、密封性同时决定低音进得来和声音出得不去

入耳式的工作方式是把振膜与耳道之间的空气封成一个小腔。低频时腔体主要表现为声顺，振膜推动的体积速度在小容积里直接转成声压，所以很小的位移就能建立可观的低频声压。这个增益是几何给的，不是电路给的。

开放式没有这个封闭腔，振膜前后辐射在远场反相叠加。低频波长远大于单元尺寸，前后抵消尤其彻底，工程上把这层现象叫声短路：未装载的振膜在低频段辐射效率急剧下降，输出幅度在谐振频率以下按斜率滚降。换句话说，开放式不是"低音调得薄一点"，而是换能器在低频本来就辐射不出那么多能量。

同一份没进入耳道的能量去了近场空气，这就是漏音。因此"密封性同时决定低音进得来和声音出得不去"这句话在物理上是同一个约束的两面：把界面封起来，两边同时改善；封不起来，任何一侧的改善都要从另一侧借。

还有第二个容易被忽略的效应：开放式听感里的低频强烈依赖佩戴位置。出音口离耳道口几毫米的差别，对低频电平的影响比均衡器上一两分贝的调节更大。这意味着实验室里测出来的低频响应，和用户实际戴偏之后的响应，不是同一条曲线。做产品验收时，位置变化要作为一项被测条件，而不是"用户正确使用"的免责条款。

## 二、四条补偿路线与各自的代价

**定向声学与近耳导管。** 把出音口做短、贴到耳廓入口附近，用缩短传播路径来提高耦合，再用波导或多口阵列把能量聚成较窄的波束指向耳道。代价是角度敏感性：波束只在有限角度带内有效，头发、帽檐、眼镜腿、夹持位置偏一点，低频就掉，而掉低频的表现是"换个姿势声音就变了"。阵列与波导还额外吃结构空间。

**双单元反向抵消漏音。** 加一个辅助辐射源，向外辐射与主辐射反相的成分，在远场抵消漏音，同时保持近耳一侧的有效声压。这条路的风险在于抵消质量取决于几何与频率：路径差在低频很难做够，抵消在近场不完全、在远场随角度和距离变化，稍有结构变形就退化；多一颗单元意味着更多功耗、更多体积，以及两个单元之间的相位一致性要求。

**等响曲线动态补偿。** 依据人耳等响特性，低音量时对小信号频段做更多提升、大音量时收敛回来，让主观响度与频谱在不同音量下更一致。代价是可换能量有限：电域提升的量最终要由振膜位移兑现，低频段最容易触到位移极限与削顶失真，因此必须配限制器与热模型，而限制器一旦频繁介入，动态被压掉，表现就是"音量一大就糊、就发硬"。判断这条路线做得好不好，看的是补偿介入时的失真增长曲线，不是静态频响图。

**头动追踪维持声场。** 开放式很难让声像落在体外，头部转动时声场跟着头走，需要靠惯性测量单元把渲染的声场锚定到空间。代价是延迟与标定：追踪链路延迟超过感知阈值会引发不适；设备在耳上的安装姿态各不相同，需要一次性标定并处理漂移；走路与晃动带来的振动会进惯性数据，滤波不干净就出现声场抖动。它是典型的"增加复杂度去修一个主观问题"的路线，收益依赖个体差异。

四条路可以叠用，但叠加顺序要定：几何先做能做的（路径与朝向），电域补偿只做残余量，抵消单元放在最后。反过来先用电域堆低频，等于把结构没做到的部分让振膜硬扛。

## 三、体积三方挤占与续航预算怎么算

单元体里同时争空间的有三方：电芯、电路（解码与降噪处理器、功放、麦克风、传感器）、蓝牙天线。天线最容易被亏待，因为它需要净空区和地平面的开窗，而耳夹结构里的弹性金属件、磁铁与扬声器磁路都在它附近，一旦失谐，回波损耗变差，链路预算不足就要靠提高发射功率补，反过来吃掉续航。电路要保功能，电芯要保时间，结构要保佩戴舒适与夹持力，四方共同决定堆叠顺序，最后被"重量与重量分布"这一条重新约束——夹持端变重会掉稳定性，配重后移会顶到耳廓。

续航不适合用单一标称小时数讨论，应该按能量算，而且必须按最恶劣工况算。

```python
# 符号化预算：容量、电压与电流用变量表示，实际取值由自测数据填入
def usable_energy_mwh(cell_mah, v_nom, dod):
    return cell_mah * v_nom * dod          # dod 为可用放电深度

def play_hours(cell_mah, v_nom, dod, avg_ma):
    return usable_energy_mwh(cell_mah, v_nom, dod) / (avg_ma * v_nom)

# 平均电流按工况分项相加，而不是取一个"典型值"：
#   蓝牙基带（编码与重传）+ 处理器与传感器 + 功放静态 + 声学负载动态
# 声学负载那一项随音量与低频补偿量上升，最恶劣工况是补偿拉满且音量最大
```

要区分三条线：连续播放、含通话的混合工况、待机在盒内的自消耗。声学负载那一项随音量与低频补偿量上升最快，把补偿拉满且音量最大是最恶劣工况，此时峰值电流若超过供电回路的输出能力，母线电压跌落会触发欠压复位，现象是"听着听着重启"而不是"电量用完了"。充电盒侧按单元容量、可循环次数与两端转换损耗推算能给单元补几次，并注意盒内充电也走同一个回路，盒的电芯选择与热设计要一起算。循环次数与电芯寿命在长期佩戴场景里是一致性问题：容量衰减后，低频补偿与高音量工况最先撑不住。

## 四、佩戴检测：少了密封度信号之后靠什么

入耳式做佩戴检测有个天然优势——密封度本身可测。反馈通路里传函的形状随腔体密封程度变化，加上耳道内的接近与电容变化，两个信号一起就能把"在耳上、在耳道里、在桌上"分得比较开。开放式把密封度这一路整个拿掉了，剩下能用的信号边界都很硬。

电容与接近类传感器（含红外）判断的是"有东西靠近"，判断不了"靠近的是耳朵"。手短暂遮挡、帽檐、围巾、放进上衣口袋都会给出相似读数。它的可靠用法是做二值门限加迟滞，而不是直接当佩戴事件。

惯性测量单元提供两类信息：姿态的重力方向投影，和运动特征。走路时头部有周期性特征，而大腿摆动幅度更大，据此可以区分"在耳上"和"在口袋里"；左右耳的判别也依赖重力投影与两侧运动差异。问题是静止工况——人坐着不动与设备放在桌上，惯性数据几乎一样，这类场景下靠惯性无法判定，只能靠上一个状态维持，于是出现"坐下没动，摘下却没暂停"。

自我发声探测（用自身麦克风发一路探测信号看传函）在开放形态信噪比不足，还会被用户听见，多数情况下只能当辅助。

工程上要可靠，得把这几条同时做到。

1. 多信号投票而不是单点判决：每一路传感给概率而非布尔值，融合后再出状态。
2. 双阈值加迟滞：进入与退出用不同门限，避免在临界位置反复翻转。
3. 确认时长两头收：短到用户察觉不出延迟，长到能过滤手短暂遮挡这类瞬时事件。
4. 高耗电行为只在多路都确认佩戴时开启，空间音频与主动降噪不能凭单帧启动。
5. 左右耳判定宁缺勿滥：不确定就退成立体声合并，判反了比不检测更难受。
6. 所有自动行为留一个可关掉的开关，这是验收项，不是加分项。

## 五、通话拾音：无腔体隔离下的风噪与结构声

腔体除了留住低音，还顺带给麦克风提供了一层隔离。开放式没有这层，麦克风膜片直接面对气流。风噪的低频宽带能量正好压在语音基频与第一共振峰的区间里，谱减或模型压制一旦用力，语音一起被削，对端听到"发闷、像在水下"。

麦克风布局上，差分与波束成形都需要间距和明确的几何关系，而耳夹结构能给的间距很小，小间距在低频段几乎提供不了指向性增益——这正好是风噪能量集中的频段。开口朝向同样关键，正对来风的方向，再好的算法也补不回来。

机械抗风是必须先做的一层：网布、发泡材料、导声槽与蜂窝结构都能把湍流转成可处理的小尺度流动。代价是插入损耗与谐振会改变整机频率响应，加了抗风结构就要重新校准，而不是沿用原来的增益曲线；开孔做大了又会反过来加剧低频泄漏，和第一节的声学约束撞上。

算法的边界要写清。双麦在这么小的间距下自由度有限，主要价值在于用两路能量差估计风强并切换策略；单麦降噪对非平稳风噪效果差；强风下降级为一路主用加动态压缩，比强行维持双麦处理更稳。还有一个只有开放式更突出的问题：结构声。音量调节、触摸、走路与夹持形变的振动会通过壳体传到麦克风，如果被判定成人声，对端会在你什么都没说的时候听到"咚、咚"。处置办法是给出音口与壳体之间的传声路径做机械解耦，或者引入一路接触式或惯性参考信号做抵消，前者是结构问题，后者要占算力。

因为麦克风离嘴更远，语音输入电平天然偏低，自动增益与语音增强会长期介入，这时可懂度和音色的损失要按整通电话评估，而不是只看安静环境下的指标。

## 六、评测该测什么：方法清单与洹拓视角

评测要测的是"这个形态在你的使用场景里能不能站住"，而不是补了多少低频。下面六项是方法，不是结论。

| 评测项 | 怎么测 | 常见误判 |
| --- | --- | --- |
| 低频下潜 | 对数扫频加低频频点纯音，在响度对齐条件下听连续性与最早失真出现的位置 | 只看静态频响图，把电域补偿的抬升当成换能器能输出的量 |
| 佩戴位置敏感度 | 同一台设备按正确位与偏几毫米各测一遍低频电平 | 只测理想佩戴，把掉低频归给"用户不会戴" |
| 漏音 | 近场校准到同一声压后，在几个固定距离与侧后方取读数，粉红噪声与含低音素材各一遍 | 只在自己听到的音量下测，或只测正后方忽略角度差 |
| 佩戴稳定性 | 固定动作序列走完，每步前后各测一次低频与漏音，看漂移 | 只测跑步，忽略穿脱上衣、戴帽与两小时后的松弛 |
| 通话 | 分风速档、分噪声场景、含手持与佩戴两种状态，对端盲听打分 | 只看频谱瀑布图，不评估可懂度与音色损失 |
| 续航 | 连续播放、混合通话、盒内循环三工况分别测，另测峰值电流最恶劣工况 | 用中等音量单工况代表全部，忽略欠压复位 |

漏音这一项还要补一个主观判断：旁人能否听出内容。同样声压级下，能听出歌词的漏音比听不出内容的漏音更成问题，这项只能在真实安静环境里做。环境感知是开放式的主要收益，也要测——出音口和支撑结构如果部分挡住耳道口，环境声反而被削弱，用一个已知的外部声源在佩戴与不佩戴两种状态下比较可闻性即可判定。

佩戴稳定性必须用固定动作序列测，顺序固定才可比。我们用的序列是：低头保持数秒、仰头、左右缓慢摇头、原地踏步、快走转为慢跑、上下台阶、戴上帽子再摘下、穿脱上衣时让夹持端被布料带一下、单耳摘戴循环、连续佩戴两小时后复测。每一步前后各取一次低频电平与漏音读数，看漂移量而不是看单点绝对值；最后一步专门验证夹持力松弛后位置偏移带来的低频衰减，因为这是长时间使用后最先出现的变化。

佩戴检测单独做一张误判矩阵：横轴是动作（摘下、手短暂遮挡、塞进上衣口袋、放桌面、戴帽或围巾遮挡），纵轴是期望状态，格子里记判定延迟与错判次数。静止工况要单独一行——坐着不动时惯性特征消失，这一格的失败模式和其他格完全不同。

洹拓视角：作为给下游做产品与交付的一方，开放式形态适不适合某个用户，取决于两件事——连续佩戴时长，以及对环境感知的真实需求。这两条都参数表里没有，也不适合拿参数表去推荐。能交付的做法是把上面的动作序列、距离与音量组合、误判矩阵写进验收文档，让用户按自己的使用方式跑一遍，再决定形态。
