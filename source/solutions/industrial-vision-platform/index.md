## 适合什么情况

- 靠人眼判定：外观缺陷、装配到位、标签印刷，靠老师傅的经验，人一累就漏
- 数据采上来但没人看：设备有运行数据，出问题还是事后翻记录
- 判定标准说不清：良品与不良的边界只在几个人脑子里，换个人就漂移

先说清一件事：如果现场连"什么算不良"都没有成文标准，第一步不是买相机，是把判定标准写下来。

## 我们怎么做

**第一步 · 定义判定**：和工艺、质检一起把缺陷类型、判定边界、抽检规则写成可执行的表。这一步决定后面所有环节的对错。

**第二步 · 成像方案**：相机、镜头、光源、安装位置的选型与打光试验。工业视觉的效果八成取决于成像质量，光打不对，模型再强也没用。

**第三步 · 数据与标注**：现场采集、缺陷样本标注、类别不平衡处理。初期样本少的时候，先用规则 + 小样本模型跑起来，边生产边攒样本。

**第四步 · 模型与产线集成**：检测模型部署到工位机或边缘盒子，和 PLC、 MES、 报警灯、剔除机构对接，节拍必须满足产线要求。

**第五步 · 闭环运营**：误判与漏判的复核界面、标注回流、模型版本管理。没有这个闭环，上线三个月后精度就会往下掉。

## 交付物

| 内容 | 说明 |
| --- | --- |
| 成像与安装方案 | 相机/镜头/光源选型、支架与打光方式、现场安装 |
| 检测软件 | 工位端界面、判定结果留档、报警与剔除联动 |
| 判定标准表 | 缺陷类型、边界定义、抽检与复核算法规则 |
| 数据与模型资产 | 标注数据集、模型权重、版本与回滚方式 |
| 看板 | 良率、缺陷分布、班次对比、设备状态 |

## 验收看什么

- 用事先约定的验证集测：漏检率、误检率分别达到多少，谁承担误判成本
- 节拍：单件检测耗时是否满足产线速度，不能为了精度拖慢生产
- 稳定性：连续运行与换型（换产品规格）后的表现
- 现场可用性：质检员会不会用、复核一条记录要几秒

## 常见坑

- 拿实验室数据集的准确率当验收指标：现场光照、抖动、来料差异会吃掉一大截性能。
- 只想替代人，不想留复核：漏判一次的责任成本远高于省下的一个人力，先把人机协同跑顺。
- 设备联网一步到位：先解决"数据能上来、能存住"，再谈分析与预测。
- 忽略换型：产品一改规格，视觉方案就要重调，交付时要把换型流程做成半自动。
